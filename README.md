# أطلس جسم الإنسان ثلاثي الأبعاد

موقع تعليمي تفاعلي لاستكشاف تشريح جسم الإنسان بثلاثة أبعاد، بواجهة عربية، ويعمل **بدون إنترنت** بعد أول زيارة.

- 2,234 جزءاً تشريحياً قابلاً للتحديد، و15 جهازاً، وبحث بالعربية والإنجليزية في 3,432 مصطلحاً.
- عزل أي جزء، وتفكيك الجسم إلى أجزائه، وتدوير وتقريب باللمس أو الفأرة.
- تطبيق ويب قابل للتثبيت (PWA): يُحفظ الموقع والنماذج (حوالي 33 ميغابايت) على الجهاز تلقائياً.

**الموقع:** https://kbs7s.github.io/anatomy-3d/

## التشغيل محلياً

يتطلب Node.js 22.13 أو أحدث.

```sh
npm ci
npm run dev      # خادم التطوير على http://localhost:3016
npm run build    # بناء الموقع الثابت في dist/
```

## النشر

كل دفع إلى الفرع `main` يبني الموقع وينشره تلقائياً على GitHub Pages عبر `.github/workflows/deploy.yml`.
في إعدادات المستودع: **Settings → Pages → Source = GitHub Actions**.

## العمل بدون إنترنت

- `pwa/sw-template.js`: الـ Service Worker. يخزّن واجهة الموقع عند التثبيت، ويخزّن ملفات النماذج أثناء تحميلها، ثم يقدّمها من الجهاز.
- `pwa/vite-plugin-pwa.ts`: يولّد `dist/sw.js` عند البناء بقائمة الملفات ورقم إصدار، فيُحدَّث التخزين تلقائياً عند تغيير الموقع، ولا تُعاد تنزيل النماذج إلا إذا تغيّرت.
- `public/manifest.webmanifest` والأيقونات في `public/icons/`.

## الترجمة

النصوص العربية وأسماء الأجهزة والأعضاء في `app/i18n-ar.ts`. الأجزاء التي لا تملك اسماً عربياً بعد تظهر باسمها الإنجليزي.
